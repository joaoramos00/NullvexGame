# Bot do Stage 2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar o autopilot (StageBot) que atravessa o Stage 2 expandido, com a derrapagem desligada no modo bot, validando a travessia da fase.

**Architecture:** Reusa o sistema existente: `DebugBoot` (flags `?stage=2&bot=1&noenemies=1`) + `StageBot` (`tests/bot/stage_bot.gd`, segue um path de segmentos). Adiciona o path `tests/bot/paths/stage_02.gd`, faz o `stage_02_scene` spawnar o bot e dar spawn por zona (`?zone=N`), abre o CP2 automaticamente no modo bot, e torna o `ice_floor.gd` (derrapante) um no-op quando `DebugBoot.bot_enabled`.

**Tech Stack:** Godot 4.6.2, GDScript. StageBot segmentos: `walk_to`/`dash_to`/`jump_to`/`wait`/`zone`/`screenshot`.

```gdscript
# Spawna o autopilot (validação da fase) quando ?bot=1.
func _maybe_spawn_bot() -> void:
	if not DebugBoot.bot_enabled:
		return
	var bot := preload("res://tests/bot/stage_bot.gd").new()
	bot.name = "StageBot"
	add_child(bot)

# Debug ?zone=N: spawna o player no início de uma zona (calibrar trechos isolados).
func _apply_debug_zone_spawn() -> void:
	if DebugBoot.zone <= 0 or not is_instance_valid(_player):
		return
	var pos := _zone_spawn(DebugBoot.zone)
	if pos == Vector2.ZERO:
		return
	_player.global_position = pos
	StageManager.spawn_position = pos

func _zone_spawn(zone: int) -> Vector2:
	match zone:
		1: return Vector2(200.0, 720.0)      # início Z1
		2: return Vector2(5700.0, 720.0)     # início Z2
		3: return Vector2(13300.0, 720.0)    # início Z3
		4: return Vector2(18100.0, 720.0)    # início Z4
		5: return Vector2(12500.0, 720.0)    # pós-miniboss (entrada do CP2)
		_: return Vector2.ZERO               # zona 1 = início normal
```
